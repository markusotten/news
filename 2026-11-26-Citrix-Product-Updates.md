# Citrix Product Updates
*Last 24 hours — 2026-11-26*

## Citrix

### Citrix SecurAccess ZTNA (service)
- **AI security for agents and MCP servers (Nov 25, 2026):** SecurAccess ZTNA adds a security layer that sits inline between AI agents and the tools they call, such as Model Context Protocol (MCP) servers. Admins can find which tools are in use, set MCP access policies with least privilege, and control what autonomous agents may do with company resources. ([What's new](https://docs.citrix.com/us/en/citrix-secure-private-access/service/whats-new.html#25-november-2026), [AI security](https://docs.citrix.com/us/en/citrix-secure-private-access/service/ai-security.html))
- **Remote Browser Isolation with Chrome Enterprise Premium (Nov 25, 2026):** Admins can list domain names (FQDNs) and wildcards that always open in Citrix Remote Browser Isolation when users work with Chrome Enterprise Premium. ([What's new](https://docs.citrix.com/us/en/citrix-secure-private-access/service/whats-new.html#25-november-2026))
- **Google AD sync and configuration checks (Nov 25, 2026):** When an admin adds a user or group to a policy, policy modeling now checks that it exists in Google AD. It also finds nested groups used in access or browser policies and confirms they are synced and set up correctly. ([What's new](https://docs.citrix.com/us/en/citrix-secure-private-access/service/whats-new.html#25-november-2026))

### Citrix Workspace app for Linux 2611 (Early Access Release, Nov 25, 2026)
A preview build for testing only, not for production. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html))
- **Keyboard tab in Preferences:** Users can change keyboard shortcut scope, layout sync and input mode inside a running HDX session. Changes apply right away, without the terminal or the configmgr tool. Useful on thin clients such as eLux. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#keyboard-settings-in-preferences))
- **Desktop Viewer toolbar improvements:** The desktop name shows when you hover over the toolbar and in dialogs and notifications. A new "Show local desktop" option minimizes all desktop sessions at once. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#desktop-viewer-toolbar-enhancements))
- **Adaptive webcam bitrate:** Webcam video quality now changes on its own with the available bandwidth, so video calls keep working on weak networks. No setup needed. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#adaptive-webcam-bitrate))
- **Chromium Embedded Framework 152 for Browser Content Redirection:** The browser engine used by BCR is upgraded to get the latest security and stability fixes. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#version-upgrade-for-chromium-embedded-framework))
- **Non-US keyboards and input methods in Browser Content Redirection:** Redirected web pages now support non-US layouts, Caps Lock and input method editors (IMEs). ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#non-us-keyboard-layouts-and-input-methods-in-browser-content-redirection))
- **QUIC as HDX transport:** HDX sessions can run over QUIC, a UDP protocol that is always encrypted with TLS 1.3 and handles slow, lossy networks well. It works for direct connections and through NetScaler Gateway 14.1-75.14 or later. It needs 2611 VDA, Delivery Controller and StoreFront, and the "HDX adaptive transport V2" policy. A VDA uses either QUIC or EDT, not both. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#support-for-quic-as-an-hdx-transport-protocol))
- **Configurable latency thresholds for the Connection Strength Indicator:** The indicator now uses the ICA round-trip-time thresholds set in policy, instead of fixed values. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#configurable-rtt-thresholds-for-the-connection-strength-indicator))
- **Clipboard sharing scope:** Admins can use a Studio policy to limit where users can copy and paste between the device and sessions. Needs Windows VDA 2607+ or Linux VDA 2603+. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#clipboard-sharing-scope))
- **Web sign-in:** Users can sign in to or unlock virtual desktops with Microsoft Entra ID through a local browser. Admins can set which browsers are tried and in what order. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#support-for-web-sign-in))
- **Crash reporting:** Crashes of app components are sent automatically to Citrix (through Sentry, hosted in the US) as part of CEIP. On by default, and can be turned off. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#crash-reporting))
- **Smart card to LDAP fallback:** Through Citrix Gateway, users without a working smart card can choose "Sign in with another method" and use user name and password instead. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#smart-card-to-ldap-fallback-authentication))
- **Pre-filled user name:** Admins can lock a device to one user by setting the user name in sessions.ini. Users only enter their password. Basic authentication only. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#support-for-pre-populated-user-name))
- **Trusted store list for browser launches:** Admins can list the store host names that the app will accept launches from when started in a web browser. All other launches are blocked. Off by default. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#trusted-store-list-for-browser-launches))
- **Launch status indicator improvements (Technical Preview):** The status card now also shows browser launches and session reconnects, and users can cancel a launch. Still off by default. ([Next release preview](https://docs.citrix.com/us/en/citrix-workspace-app-for-linux/ear.html#launch-status-indicator-enhancements-(technical-preview)))
