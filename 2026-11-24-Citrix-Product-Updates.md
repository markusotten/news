# Citrix Product Updates
*Last 24 hours — 2026-11-24*

## XenServer

### XenServer 8.4 (Normal update channel)
- **Nov 19 update bundle now on the Normal channel – security fixes (Nov 19, 2026):** The security fixes first released to Early Access on Nov 19 are now available to Normal-channel pools. Details are in the linked XenServer security bulletin. ([XenServer 8.4 – Normal channel updates](https://docs.xenserver.com/us/en/xenserver/8/whats-new/normal.html))
- **Fix: Control domain memory corruption with some local storage controllers (Nov 19, 2026):** Normal-channel pools now get the fix for rare dom0 memory corruption caused by certain local storage controllers. ([XenServer 8.4 – Normal channel updates](https://docs.xenserver.com/us/en/xenserver/8/whats-new/normal.html))
- **Fix: Expired CIFS/SMB password blocks operations (Nov 19, 2026):** An expired CIFS/SMB password now returns an error on the Normal channel too, instead of leaving some operations hanging forever. ([XenServer 8.4 – Normal channel updates](https://docs.xenserver.com/us/en/xenserver/8/whats-new/normal.html))

### XenServer 9 (Normal update channel)
- **Nov 19 update bundle now on the Normal channel – security fixes (Nov 19, 2026):** XenServer 9 pools on the Normal channel can now install the Nov 19 security fixes. Details are in the linked XenServer security bulletin. ([XenServer 9 – Normal channel updates](https://docs.xenserver.com/us/en/xenserver/9/whats-new/normal.html))
- **Fix: Control domain memory corruption with some local storage controllers (Nov 19, 2026):** The fix for rare dom0 memory corruption with certain local storage controllers reaches XenServer 9 Normal-channel pools. ([XenServer 9 – Normal channel updates](https://docs.xenserver.com/us/en/xenserver/9/whats-new/normal.html))
