# Citrix Product Updates
*Last 24 hours — 2026-11-14*

## Citrix

### Citrix Remote Browser Isolation

- **Okta SAML 2.0 sign-in from Citrix Workspace (November 2026, published Nov 13, 2026):** RBI now accepts Okta as a SAML 2.0 identity provider when users sign in through Citrix Workspace. Admins set up Okta SAML 2.0 under Identity and Access Management in the Citrix Cloud console and choose SAML 2.0 as the identity provider for StoreFront Cloud Authentication. Users then open RBI apps from Workspace with single sign-on. ([RBI – What's new](https://docs.citrix.com/en-us/citrix-remote-browser-isolation/whats-new.html))

## NetScaler

### NetScaler Console service

- **Corrected CVE list for the November 12 Security Advisory update (revised Nov 13, 2026):** The November 12 entry has been revised. Security Advisory still covers 28 CVEs, but the list has changed: CVE-2026-107407 to -107415, CVE-2026-111333 to -111342, and CVE-2026-120860 to -120868. Detection still needs a version scan, and the fix is still to upgrade affected instances to a recommended build. ([NetScaler Console service – What's new](https://docs.netscaler.com/en-us/netscaler-console-service/release-notes/whats-new.html))
