## Citrix

### uberAgent
- Released uberAgent 8.1, adding support for uberAgent for IGEL OS 12, deployable via the IGEL Universal Management Suite (requires IGEL OS 12.8.0 or later; manual installation only for now).
- Discontinued the Azure Monitor backend ahead of Microsoft's deprecation of the HTTP Data Collector API on September 14, 2026.
- Improved Citrix VDA detection and added a new receiver-level `EnableExtendedInfo` control for EventDataFilter configurations.
- Updated the Splunk dashboard with clearer licensing-status visualization.

([docs.citrix.com](https://docs.citrix.com/en-us/uberagent/current-release/whats-new.html))
