# Citrix Product Updates
*Last 24 hours — 2026-10-28*

## Citrix ([docs.citrix.com](https://docs.citrix.com))

### Citrix DaaS — [What's new](https://docs.citrix.com/en-us/citrix-daas/whats-new.html) (October 2026)
- **Autoscale catalog failover (primary and backup catalogs):** Mark one or more machine catalogs in a delivery group as primary so Autoscale powers on machines only from them. When the primary catalogs run out of capacity, Autoscale fails over to the backup catalogs and fails back automatically once the primary catalogs recover. Configured with the Broker PowerShell SDK. See [Configure catalog failover](https://docs.citrix.com/en-us/citrix-daas/whats-new.html).
- **Scoped images for CSP multitenant DaaS:** Images can now be prepared per tenant scope. Partner administrators assign each image to a tenant scope; images prepared by a tenant administrator are assigned to that tenant's scope automatically, and tenant administrators manage the images their catalogs need within their scope.

### StoreFront Cloud — [What's new](https://docs.citrix.com/en-us/citrix-workspace/whats-new.html) (October 2026)
- **Custom domains with Citrix Cloud Government:** You can now configure custom domains when using Citrix Cloud Government.
