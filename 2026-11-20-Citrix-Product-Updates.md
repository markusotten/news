# Citrix Product Updates
*Last 24 hours — 2026-11-20*

## XenServer

### XenServer 8.4 (Early Access update channel)

- **Security update (Nov 19, 2026):** The Nov 19 Early Access update bundle includes security fixes. The details are in the linked XenServer security bulletin. ([XenServer 8.4 – Early Access updates](https://docs.xenserver.com/en-us/xenserver/8/whats-new/early-access.html))
- **Fix: Control domain memory corruption with some local storage controllers (Nov 19, 2026):** Fixes a rare problem where certain local storage controllers could corrupt memory in the control domain (dom0). ([XenServer 8.4 – Early Access updates](https://docs.xenserver.com/en-us/xenserver/8/whats-new/early-access.html))
- **Fix: Expired CIFS/SMB password blocks operations (Nov 19, 2026):** An expired CIFS/SMB password now produces an error. Before this fix, some operations could hang indefinitely. ([XenServer 8.4 – Early Access updates](https://docs.xenserver.com/en-us/xenserver/8/whats-new/early-access.html))

### XenServer 9 (Early Access update channel)

- **Security update (Nov 19, 2026):** The Nov 19 XenServer 9 Early Access update bundle includes security fixes. The details are in the linked XenServer security bulletin. ([XenServer 9 – Early Access updates](https://docs.xenserver.com/en-us/xenserver/9/whats-new/early-access.html))
- **Fix: Control domain memory corruption with some local storage controllers (Nov 19, 2026):** XenServer 9 gets the same fix for rare dom0 memory corruption on certain local storage controllers. ([XenServer 9 – Early Access updates](https://docs.xenserver.com/en-us/xenserver/9/whats-new/early-access.html))
